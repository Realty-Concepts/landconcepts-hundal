# Hundal Land Portfolio Auction

One-page site for a single-seller auction of about 20 land properties, marketed by [Land Concepts](https://www.mylandconcepts.com/).

Not a general brokerage homepage — branding and About content come from Land Concepts; the page itself is dedicated to this auction.

## Stack

- Vite + React + TypeScript

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
